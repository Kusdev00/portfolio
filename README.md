# Markus — Portfolio

Dark-themed, coding/terminal-inspired portfolio for a 17-year-old Python developer from Estonia.

**Live:** https://kusdev00.github.io/portfolio/

## Tech Stack

- Next.js 15 (static export)
- Tailwind CSS 4
- Framer Motion
- JetBrains Mono font
- GitHub Pages

## Sections

- **Hero** — Terminal-style intro with syntax-highlighted code
- **About** — Who I am, what I do
- **Skills** — Animated progress bars
- **Projects** — Code editor-styled cards (AI Clipper, ScrapePro, Trend Engine, Video Generator)
- **Experience** — Timeline with glow effects
- **Contact** — Social links + form

## Local Dev

```bash
npm install
npm run build
```

Output goes to `out/` — deployed via `gh-pages` branch.
