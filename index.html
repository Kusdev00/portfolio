scrapepro_case.md

ScrapePro — extracting data that changes shape

// problem

Scraping breaks whenever a site's layout shifts, and every new site usually means rewriting selectors by hand.

// approach

Built a CLI toolkit that auto-detects page structure, supports CSS/XPath selectors, crawls sites, and re-checks pages for changes — so one tool covers many sites instead of one script per site.

// result

Exports to 4 formats (JSON, CSV, XLSX, SQLite), change detection flags updated pages, no per-site code required for standard layouts.

"Python""CLI""CSS/XPath""SQLite".source()
aiclipper_case.md

AIClipper — turning long videos into vertical clips

// problem

Cutting long videos into 9:16 shorts is slow manual work: crop, blur, subtitles, render — repeated for every clip.

// approach

Designed a Flask REST API with a concurrent job queue: clients submit a video, workers run FFmpeg blur effects for 9:16 output and generate subtitles with Kokoro TTS, rendering automatically.

// result

One submission produces a finished vertical clip with burned-in subtitles — no manual editing steps, jobs processed in parallel instead of one at a time.

"Python""Flask REST API""FFmpeg""Kokoro TTS".source()
